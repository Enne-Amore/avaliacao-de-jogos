# 🎮 Avaliação De Jogos

 Website feito para fazer avaliação de jogos. Projeto proposto pelo professor da matéria Tópicos Especiais em Sistemas Para Internet (TESPI).


## 🌐 Aplicação Hospedada

 [Clique aqui para acessar o website](https://enne-amore.github.io/avaliacao-de-jogos/)


## ⚡ Funcionalidades

 - Menu de navegação por páginas abrível e fechável
 - Mais acessibilidade usando a tecla "tab"
 - Efeitos de "hover" e de "active" nos elementos  clicáveis
 - Botão de voltar ao topo da página
 - Scroll horizontal arrastando através do clique do mouse nos carrosséis de imagem
